### 🧩 关于我们
FosuSec 是佛山大学的网络安全实验室。
我们热爱信息安全、漏洞挖掘、CTF 竞赛、密码数学、安全工具开发。
团队成员共同学习、交流攻防技术，输出开源工具、学习笔记、竞赛源码。

✅ 研究方向：
- CTF 夺旗赛（Web / Pwn / Crypto / Reverse / Misc）
- 网络协议、内网渗透、流量分析
- 密码学与后量子密码研究
- 安全开发、Python / Go 安全工具
- 开源安全项目维护
